# Agent Documentation

Folder ini berisi instruksi operasional untuk AI atau developer. Folder ini
bukan runtime aplikasi dan bukan sumber aturan bisnis baru.

## Titik mulai

1. Baca [`AGENTS.md`](../../AGENTS.md).
2. Baca [`PROJECT-CONTEXT.md`](../PROJECT-CONTEXT.md).
3. Baca [`../00-INDEX.md`](../00-INDEX.md), lalu dokumen canonical yang relevan dengan task.

`AGENTS.md` adalah instruksi agent canonical. [`00-SOURCE-OF-TRUTH.md`](../business/00-SOURCE-OF-TRUTH.md)
adalah sumber aturan bisnis tertinggi. Jika ada konflik, jangan menebak.

## Dokumen dalam folder ini

- [`34-PROMPT.md`](34-PROMPT.md) — aturan prompt umum dan batasan kerja.
- [`35-PROMPT-NEW-PROJECT.md`](35-PROMPT-NEW-PROJECT.md) — project dari nol.
- [`36-PROMPT-EXISTING-PROJECT.md`](36-PROMPT-EXISTING-PROJECT.md) — project yang sudah ada.
- [`37-IMPLEMENTATION-WORKFLOW.md`](37-IMPLEMENTATION-WORKFLOW.md) — alur kerja task.
- [`38-DOCUMENTATION-READING-ORDER.md`](38-DOCUMENTATION-READING-ORDER.md) — urutan baca sesuai task.
- [`39-DEFINITION-OF-DONE.md`](39-DEFINITION-OF-DONE.md) — kriteria pekerjaan selesai.

Dokumen ini sengaja ringkas agar dapat digunakan oleh AI ringan dan AI dari
platform mana pun.
