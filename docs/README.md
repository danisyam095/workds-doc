# Application Documentation

Seluruh dokumentasi aplikasi Marketing Asisstant berada di `docs/`.

Mulai dari [00-INDEX.md](00-INDEX.md) untuk peta task, lalu baca
[PROJECT-CONTEXT.md](PROJECT-CONTEXT.md) untuk ringkasan singkat
yang dapat dibaca AI ringan. Setelah itu baca dokumen canonical yang relevan
sesuai task; tidak perlu membaca seluruh folder.

| Folder | Dokumen |
|---|---|
| `business/` | Source of truth dan proses bisnis |
| `architecture/` | Arsitektur, database, data dictionary, migration, dan policy |
| `api/` | API specification |
| `backend/` | Backend implementation dan infrastructure |
| `features/` | Feature specifications |
| `testing/` | Invariant dan test matrix |
| `planning/` | Implementation order |
| `operations/` | Production operations guide |
| `agent/` | Prompt dan workflow agent |
| `operations/` | Deployment, environment, migration, backup, observability, incident, security, go-live |
| `archive/audit/` | Audit dan resolution documents historis |

`AGENTS.md` berada di root sebagai satu-satunya instruksi agent canonical.
Dokumen operasional agent 34–39 berada di root `docs/agent/`. Nomor 33 tidak digunakan sebagai salinan AGENTS.
